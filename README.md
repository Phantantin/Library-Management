# Library Management backend

Spring Boot API for the Folio Library platform. The Next.js application is in the sibling `../frontend` directory. Start with the workspace [README](../README.md), then read [docs/01-system-overview.md](docs/01-system-overview.md), [docs/03-api-contract.md](docs/03-api-contract.md) and [docs/08-development-setup.md](docs/08-development-setup.md).

Run tests with `.\mvnw.cmd test` on Windows or `./mvnw test` elsewhere. Secrets and local configuration belong in environment variables or the ignored `application-local.properties` file.
